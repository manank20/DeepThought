DeepThought v2 keeps the reusable surface small and explicit: semantic templates, a local stylesheet, vanilla JavaScript, and optional rich-content components. The demo is intentionally generic so it can be copied without inheriting someone else's identity or content.

Read the [configuration guide](/docs/config-options/) or start with the [small example post](/posts/post-0/).
